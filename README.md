# ManaNet

Futuristic network-defense tower defense game — Godot 4.6 port of the Python/Kivy TowerDefenseKivy.

- **Stack:** Godot 4.6, GDScript
- **Package:** com.mananet.godottd
- **Build:** Open in Godot 4.6 Editor
- **Agent docs:** CLAUDE.md, PROJECT_CONTEXT.md, AGENTS.md
- **Art contract:** `art/ART_DIRECTION.md` and `art/contracts/mananet_asset_contract.yaml`
- **Runtime asset proof:** `python scripts/asset_validation/validate_asset_pack.py --runtime-evidence build/verification/runtime_asset_coverage_visual.json`
- **Runtime certification scene:** `godot --scene res://tests/runtime/RuntimeAssetCertification.tscn`
